# 2026-09-25 · 프론트엔드 아키텍처 이관

목표: vanilla JS SPA → Vite + React + TypeScript. 제품 재설계가 아니라 유지보수성·타입
안전성·병렬 agent 개발을 위한 구조 변경.

상태: **완료.** `npm test`, `npm run typecheck`, `npm run build`, 브라우저 회귀 72개 모두 통과.

## 결과

`app.js`(61KB, 396줄) 삭제. React가 유일한 프론트엔드 런타임.

```
src/
  main.tsx       #app에 React root mount
  app/           router.ts · App.tsx · store.ts
  components/    Paper(원문 카드·빈칸·360px 축소) · StudyShell · Navigation · useStudyKeys · AccessPanel
  features/      memorize recall blanks compare timeline order quiz coach (모드별 폴더)
  lib/           data text state cloze questions cloud snapshot toast (DOM 비의존)
  types/         domain.ts · globals.d.ts
```

기능별 폴더가 나뉘어 있어 앞으로 Codex/Claude worker가 서로 다른 모드를 동시에 수정해도
같은 파일에서 충돌하지 않는다. 이게 이번 이관의 실제 목적이었다.

### 핵심 설계 결정

학습 상태는 React state가 아니라 `src/lib/state.ts`의 mutable 모듈로 유지했다.
입력 한 글자마다 리렌더링하지 않기 위한 선택이고, **이것이 한글 IME 조합이 깨지지 않는
이유다.** 상태 변경 뒤에는 `src/app/store.ts`의 `refresh()`를 호출하고, 각 route는
`useSyncExternalStore`로 구독한다. 전역 상태 라이브러리는 넣지 않았다.

## 검증

`test.mjs`의 단언·입력·기대값은 하나도 바꾸지 않았다. 다만 **`app.js` 소스를 문자열로
잘라내 eval하던 방식**을 실제 모듈 import로 교체했다. 이게 217개 학습 단위 전체와
모든 주제/분량/세트 조합에 대해 추출이 정확했음을 view 재작성 전에 증명해 줬다.

`test-browser.mjs` 신규: QA_REPORT.md 동작 목록을 72개 항목으로 자동 확인.
실행은 `node test-browser-server.mjs &` 후 `npm run test:browser`.

### 이관 중 발견한 문제 3가지

1. **빈칸 입력을 controlled로 만들면 한글 IME가 깨진다.** 일부러 시험해 봤고, 조합 중
   텍스트가 기존 draft에 덮여 `감` 대신 `테스트감`이 입력됐다. uncontrolled로 유지했고,
   CDP `Input.imeSetComposition` 실제 조합 이벤트로 회귀 검사를 걸어 뒀다.
2. bridge 구간에서 React와 legacy 키보드 핸들러가 동시에 붙어 Alt+←/→가 두 번 먹혔다.
3. `useRefresh`가 호출한 컴포넌트만 리렌더링해서, 카드 이동 시 nav는 갱신되는데 카드는
   그대로였다. store 구독 방식으로 교체.

## 남은 부채 (MIGRATION.md에 상세)

1. `resizePapers`가 여전히 DOM 측정 후 inline style을 쓴다. CSS container query로 지울 수
   있지만 시각 레이어 변경이라 이번 범위 밖.
2. 번들 1개, 원본 670KB. `data.js` 385KB가 즉시 로드된다. route별 `React.lazy` + 데이터
   동적 import는 별도 작업.
3. `data.js`/`question-bank.js`는 원문 보존 때문에 여전히 `window` 전역. 재생성 시 ES
   module로 바꾸면 `globals.d.ts`를 지울 수 있다.
4. `src/package.json`은 `test.mjs`가 타입 모듈을 직접 import하기 위한 것. root를
   `"type": "module"`로 바꾸려면 `api/study.js`를 먼저 ESM으로 옮겨야 한다.
5. 컴포넌트 단위 테스트 없음. 현재는 Node 검사(도메인·API) + 브라우저 검사(동작)로 커버.
6. `QA_REPORT.md`는 이관 전 빌드 기준(2026-09-22). 재실행하거나 폐기 필요.

## 의존성 변경

추가: `react` `react-dom` (dependencies) / `vite` `@vitejs/plugin-react` `typescript`
`@types/react` `@types/react-dom` `playwright-core` (devDependencies).
`playwright-core`는 브라우저를 내려받지 않고 `npm test`도 의존하지 않는다. 불필요하면
`test-browser.mjs`와 함께 빼면 된다.
